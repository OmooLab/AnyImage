# 立体裁切

**立体裁切**可以圈出图片中的主体，并把它变成一个独立形状。

背景比较复杂时，可以先用 **移除背景** 得到透明背景，轮廓会更容易选择。

## 圈选主体

选中参考图片（Image Empty），在 3D 视图左侧工具栏选择 **立体裁切**。工具栏隐藏时，按 **T** 打开。

在顶部工具设置中选择 **套索** 或 **折线**，然后沿主体轮廓圈选。完成后，从弹出的菜单中选择形状。

![使用套索圈选主体，并打开立体裁切形状菜单]()

## 选择形状

- **平面**：平面的剪贴形状。
- **实体**：带厚度的剪贴形状。
- **深度对称**：前后对称的深度形状。
- **深度实体**：按图片深度生成的立体形状。

如果轮廓太粗或细节太多，可以调整顶部的 **边长** 和 **精细轮廓**，再重新圈选。
