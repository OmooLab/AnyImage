# 其他图片工具

选中 Image Empty，右键打开 **AnyImage**，还可以找到三个直接编辑图片的工具。

## Frame

**Frame** 会把当前视角中的多张图片合成一张。

选中需要合成的 Image Empty，最后选中的图片作为 Active Object。打开 **AnyImage > Frame**，拖出一个矩形作为新的画面范围。

![选择多张图片并拖出 Frame 范围]()

## Mask

**Mask** 用来隐藏或恢复图片区域。

打开 **AnyImage > Mask**，在顶部选择 Lasso、Brush 或 Polyline，再选择编辑模式并涂画图片。

![使用 Brush 隐藏图片的一部分]()

## Rectify

**Rectify** 可以把图片中的透视四边形校正为正面矩形。

打开 **AnyImage > Rectify**，依次点选四个角。预览出现后，左右移动鼠标调整宽高比，单击确认。

![点选四角并确认 Rectify 预览]()

这些工具可以在建模前整理画面，也可以随时用来修正正在使用的图片。
