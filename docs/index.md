AnyImage 是为 Blender 准备的图片工具组。让图片不再只是参考图：粘贴进来，选出需要的部分，再把它变成带材质、轮廓与深度的场景元素。

## 从图片直接开始

在 3D View 或 Node Editor 中按 **Ctrl+Shift+V**（macOS 为 **Cmd+Shift+V**），剪贴板里的图片会直接进入当前工作区。不必先保存文件，也不用中断正在进行的搭建。

已有图片同样可以继续使用。选中 Image Empty 后，右键打开 **任意图！** 菜单，常用操作都在这里。

## 一张图，多种空间表达

- **转为平面 / 转为深度平面**：把图片变成平面或立体面片。
- **立体裁切**：圈选主体，创建**平面**、**实体**、**深度对称**或**深度实体**。
- **图片工具**：使用**重设画框**、**局部显隐**、**透视校正**、**移除背景**和**2倍高清**整理图片。
