# 烘焙网格

用图做出形状后，想继续挪顶点、改拓扑？**烘焙网格**会把当前形状和贴图固定下来，变成可以直接编辑的普通网格。

## 使用方法

先调好形状和材质，在**物体模式**选中模型，右键选择 **任意图！ > 烘焙网格**。完成后按 **Tab** 进入编辑模式，就能继续修改网格。

支持**面片**、**凹凸面**、**浮雕**、**立体全景**，以及立体裁切中的**体块**、**凹凸体块**和**对称凹凸**。

## 烘焙结果

烘焙会整理 UV 和颜色贴图，需要时生成切线空间法线贴图。已固化的修改器会移除，原来的形状参数也随之固定；想返回参数调整，可以立即撤销。

共享的材质和待更新的图片会为当前对象单独复制，其他对象保持原样。烘焙后仍可在着色器编辑器选中**图像纹理（Image Texture）**节点，继续调色、移除背景或放大贴图。
