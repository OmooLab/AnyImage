# 其他图片工具

选中 Image Empty，右键打开 **任意图！**，还可以找到三个直接编辑图片的工具。

## 重设画框

**重设画框** 通过矩形画框重新限定图片边界。选中多张图片时，画框内的内容会按当前视角合为一张图片。

选中需要重设画框的 Image Empty，最后选中的图片作为 Active Object。打开 **任意图！ > 重设画框**，拖出一个矩形作为新的画面范围。

![使用重设画框确定新的画面范围]()

## 局部显隐

**局部显隐** 用来隐藏或恢复图片区域。

打开 **任意图！ > 局部显隐**，在顶部选择**套索**、**画笔**或**折线**，再选择编辑模式并涂画图片。

![使用画笔隐藏图片的一部分]()

## 透视校正

**透视校正** 可以把图片中的透视四边形校正为正面矩形。

打开 **任意图！ > 透视校正**，依次点选四个角。预览出现后，左右移动鼠标调整宽高比，单击确认。

![点选四角并确认透视校正预览]()

这些工具可以在建模前整理画面，也可以随时用来修正正在使用的图片。
