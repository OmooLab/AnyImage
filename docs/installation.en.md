# Installation

## Requirements

- Blender 4.5 or later
- A Blender installation outside Microsoft Store or Steam, whose versions may have issues installing or loading dependencies

## Install the extension

### Drag into Blender

Drag the button below into the Blender window.

On the first drag, Blender asks you to add the AnyImage extension repository. Confirm, then drag the button in again to install.

--8<-- "docs/includes/install.html"

### Install manually

Click **download** below the installation button to download the Zip file for your system. Keep the file zipped.

In Blender, open **Edit > Preferences > Add-ons**, choose **Install from Disk** from the menu in the top-right corner, and select the downloaded Zip file.

## Start from the clipboard

After installation, press **Ctrl+Shift+V** in the 3D View or Node Editor (**Cmd+Shift+V** on macOS). The image on your clipboard is added directly to the current workspace.
