## Context

BlendJob 的磁盘任务目录与内存历史分离；结果图片正常导入后打包进 Blender。

## Decisions

- 服务端持有任务锁时执行预览及删除；活动或排队任务存在时拒绝清理。Blender 在结果导入结束前禁用入口。
- 仅处理 storage_root/jobs 下 UUID 命名的直接子目录，跳过符号链接、重解析点及未打包图片所在任务目录。
- 确认窗口显示本次候选数量与大小，执行时重新检查引用和任务状态，仅删除确认过的候选。
- 每个成功删除的目录同步移除内存历史；失败目录保留记录并报告。模型、运行环境、server.log 保留。
- 清理入口通过当前服务端执行；服务器未启动时按现有机制启动，环境未安装时禁用。模型无需卸载。
- Job Server 侧边栏集中提供完整文字的 Unload Models、Clear Job Files 与 Open Server Log。

## Risks / Trade-offs

- 删除任务产物不可撤销，外部自行引用历史产物的文件无法全面追踪；确认窗口明确提示。
- 保护范围为当前 Blender 的图片引用与所连接服务端的任务；共享目录的其他 Blender 实例需用户先关闭。
