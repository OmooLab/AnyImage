# 裁图、拼图与透视校正

把图放进场景后，也能直接裁一下、拼一拼，或把照片里斜着的画面拉正。

这些工具处理参考图片（Image Empty）。在**物体模式**选中图片，再到 3D 视图左侧工具栏选择工具；按 **T** 可以展开工具栏。

## ✂️ 重设画框

只想留下图里的一块？选择 **重设画框**，拖出矩形，松开鼠标就能裁出新的画面范围。

也可以先在场景里摆好几张图，一起选中，调整视角再画框。框内的图片会按当前视角合成一张，替换选中的图片。最后选中的图片需要与画框重叠。

## 🖌️ 局部显隐

想藏起背景的一角，或把刚才隐藏的部分找回来，用 **局部显隐**。在顶部选择**套索**、**画笔**或**折线**，再选一种显隐方式：

| 模式 | 作用 |
| --- | --- |
| 设定 | 保留选区内可见的部分，隐藏外部 |
| 扩展 | 显示选区内的部分，其他区域不变 |
| 减去 | 隐藏选区内的部分，其他区域不变 |

套索和画笔画完后松开鼠标即可。折线逐点单击，最后按 **Enter** 或双击完成；**Backspace** 撤回上一点。

## 📐 透视校正

照片里的门窗、墙面拍斜了，可以拉正后拿来做贴图。选择 **透视校正**，点出画面的四个角，顺序不限。预览出现后，左右移动鼠标调整宽高比，单击确认。

点错了按 **Backspace** 返回；操作中按 **Esc** 或右键取消。
