# 🚪 任意图！

任意图！ 让「图」成为 Blender 创作的入口。以图建模、快速贴图、拼搭场景，从参考图开始创作！

## 图不必下载，拿来就用！

在 Blender 里按 **Ctrl+Shift+V**（macOS 用 **Cmd+Shift+V**），就能快速把剪切板的图加进场景。在雕刻、纹理绘制时，粘贴会创建纹理笔刷。在节点编辑器时，则会自动创建图片节点~

## 从参考图，直接出立体模型！

用 **立体裁切** 工具圈出一部分，瞬间做出带厚度的模型，摆进场景先看看！还有把图转化为地形、浮雕、全景场景的功能哦！

![圈出立体模型](assets/demos/depth-cutout.gif)

## 还有裁图、拼图、调色！

✂️ **重设画框**：裁出想要的范围，也能把摆好的几张图按当前视角合成一张。

🖌️ **局部显隐**：用套索、画笔或折线隐藏不要的部分，也能把它们恢复回来。

📐 **透视校正**：点选四个角，把照片里斜着的画面拉正，拿来做贴图。

🎨 **色彩匹配**：挑一张参考图，统一颜色和亮度。材质里的图片贴图也能用。

## 超快 AI 小功能，无需联网！

本地直接运行移除背景、2倍高清，🈶快又好不费钱，也能直接处理材质中的图片贴图！
