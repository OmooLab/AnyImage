# 移除背景与2倍高清

**移除背景**可以在**立体裁切**前清理背景，**2倍高清**则可以让**立体裁切**使用更清晰的贴图。

第一次使用 AI 功能时，按提示完成 **设置 AI 服务器**。准备完成后，再次执行需要的功能。

## 移除背景

选中图片，右键打开 **任意图！ > 移除背景**。确认模型后，等待处理完成，背景会变为透明。

![移除背景前后对比]()

现在再使用**立体裁切**，只需沿主体大致圈选，透明区域不会进入最终形状。

## 2倍高清

选中已经创建的**立体裁切**对象，右键打开 **任意图！ > 2倍高清**。菜单会显示处理后的尺寸，完成后**立体裁切**会使用放大后的图片。

![2倍高清前后细节对比]()
