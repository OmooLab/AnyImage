# 安装

AnyImage 支持拖拽和手动安装，选择一种方式即可。

## 拖入 Blender

按住下方按钮，将它拖到 Blender 窗口中。

第一次拖入时，Blender 会询问是否添加 AnyImage 扩展仓库。确认后，再拖入一次即可安装。

## 手动安装

点击安装按钮下方的 **download**，下载适合当前系统的 Zip 文件，请勿解压。

打开 Blender，进入 **Edit > Preferences > Add-ons**，点击右上角菜单中的 **Install from Disk**，选择刚下载的 Zip 文件。

![Install from Disk 的位置]()

## 从剪贴板开始

安装完成后，在 3D View 或 Node Editor 中按 **Ctrl+Shift+V**；macOS 使用 **Cmd+Shift+V**。剪贴板中的图片会直接进入当前工作区。
