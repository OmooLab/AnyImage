# 色彩匹配

拼进场景的几张图，颜色各不相同？挑一张作为参考，让其他图片靠近它的色彩和亮度，画面就更容易统一。材质里的图片贴图也能用。

## 选择参考图片

在 3D 视图按 **N** 打开侧栏，进入 **任意图！ > 色彩匹配**。从图片画廊中选一张参考图，下方色板会显示它的主要颜色。

## 匹配目标图片

选中要调色的参考图片，或任意图！创建的图片模型，右键选择 **任意图！ > 匹配参考图色彩**。处理材质贴图时，在着色器编辑器选中带图片的 **图像纹理（Image Texture）** 节点，再从右键菜单执行。

参考与目标需要是不同的静态图片。预览出现后：

| 操作 | 调整 |
| --- | --- |
| 左右移动鼠标 | 色彩匹配强度 |
| 上下移动鼠标 | 亮度匹配强度 |
| 按住 **Shift** | 精细调整 |
| 单击或 **Enter** | 确认 |
| 右键或 **Esc** | 取消 |

确认后，图片的透明区域会保留。想再试一次，可以撤销后重新调整。
