- [x] 1.1 将唯一 active_job 改为按提交顺序保存的任务集合，进度与 controller 归属于各 Job。
- [x] 1.2 将 JobOperatorBase 全部更名为 JobOperator；每个 Operator 绑定自己的 Job，移除旧名称与兼容入口。
